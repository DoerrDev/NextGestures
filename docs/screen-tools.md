# 截图工具

主界面顶部提供截图标注、贴图、画中画和 OCR 四种入口。在手势编辑器中选择“截图工具”动作，也可以分别绑定这四种功能。

## 使用

截图框选后，可拖动选区或边缘调整范围。工具栏支持矩形、箭头、画笔、文字、马赛克、撤销、重做、复制图片和保存 PNG。Enter / Ctrl+C 复制、Ctrl+S 保存、Ctrl+Z 撤销、Ctrl+Y 重做。Esc 优先退出文字编辑或 OCR 面板，再退出截图；右键取消截图。

贴图支持多张并存、拖动、滚轮缩放和图像透明度。打开鼠标穿透后，在主界面“截图工具”的悬浮窗口列表中恢复交互或关闭。当前上限为 20 张。

画中画的选区应落在一个应用窗口内。画面由 DWM 直接合成，窗口可拖动、缩放、暂停、继续、置顶或取消置顶。源窗口最小化时暂停，恢复时继续，关闭后自动回收；最多 12 个。受保护视频、使用特殊渲染方式的窗口，以及应用主动停止后台绘制的内容，取决于 Windows 和源应用的捕获能力。

OCR 使用 Windows 已安装的识别语言包，不发送图片到网络。选择识别语言后可重试，结果可编辑并复制。中文字符间的系统分词空格会被整理，英文单词间的空格保留。大选区按 OCR 尺寸上限缩小，细小文字建议缩小选区后再识别。

锁屏或切换到安全桌面时会提示解锁后重试。此时系统剪贴板和实际画面所属桌面可能不一致，因此不启动选区。

## 实现

- `crates/platform/src/windows/screen.rs`：GDI 桌面抓取、物理像素边界、PNG 编解码、系统保存对话框和 Windows OCR。
- `crates/platform/src/windows/pip.rs`：原生 DWM 缩略图窗口。画面由合成器更新，不通过 WebView 传送连续截图。250ms 定时器只检查源窗口生命周期和最小化状态。
- `src-tauri/src/screen_tools.rs`：截图会话、专用图片 URI、独立窗口和异步任务。图像仅保留在内存；关闭窗口时移除图片和会话。
- `src/tools/`：框选、标注、OCR 结果编辑和贴图窗口。

截图/OCR/PNG 工作放在独立任务中，鼠标钩子只增加框选状态检查。截图动作统一等触发键松开后启动。框选期间临时放行输入，不改变用户的手势总开关；窗口销毁和启动失败时均恢复。

截图背景通过专用 URI 加载，避免在每次移动鼠标时传输或编码图片。导出时才生成裁剪与标注后的 PNG。像素数据有尺寸限制，负坐标裁剪使用 64 位中间计算。双 4K 图像明确放宽 PNG 解码库的默认 64MB 内存限制。

## 验证范围

自动化回归覆盖：

- 旧配置兼容、四种新动作的 TOML 往返、现有手势与黑名单测试。
- PNG 颜色和透明度往返、无效 PNG、尺寸上限、双 4K PNG 解码，以及负坐标与溢出边界。
- 在实际 WebView 中检查标注像素、撤销/重做、选区调整、两张贴图、透明度、缩放及鼠标穿透恢复。
- 实际 Windows 中英文 OCR 引擎与已安装语言包、错误图片拒绝。
- 实际原生 DWM 窗口创建、暂停/继续与关闭。
- 解锁桌面下的真实图片/文字剪贴板粘贴、系统保存对话框取消/保存/覆盖，及原生画中画动态采样、遮挡、最小化恢复与源窗口关闭。
- 八次连续开关四种工具，检查重复启动拒绝、退出后图片 URI 失效与悬浮窗口清空。
- 7680×2160 构造图跨屏裁剪像素检查，以及 100%、125%、150%、200% 的坐标换算。

构造图验证不代替真实多显示器和不同缩放设置下的实测。完整桌面验收还应检查：复制到画图和具体聊天软件、多张置顶窗口移动跨屏、不同视频源的长期播放帧率与资源占用、工具关闭后的硬件鼠标手势响应。当前小区域动态画面采样达到约 53–63 次可见变化/秒，不能据此推断 4K 视频性能。

开发验证使用 `cargo test --workspace` 和 `npm run build`。桌面测试脚本和当前测试截图保存在本地忽略目录 `output/playwright/`。
